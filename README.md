# Number Analysis Tool

A simple C++ console application that analyzes numbers entered by the user.

## Project Description

This project allows users to enter a group of numbers and performs several mathematical operations.

## Features

- Calculate the sum.
- Calculate the average.
- Find the largest number.
- Find the smallest number.
- Identify even and odd numbers.
- Count even and odd numbers.

## Technologies Used

- C++
- Arrays
- Functions
- For Loops
- If / Else Statements
- Arithmetic Operators
- Modulo Operator (%)

## How to Run

1. Download the repository.
2. Open main.cpp in a C++ compiler.
3. Compile and run the program.
4. Enter the number of elements.
5. Enter the numbers.
